# Отчет по вычислительному практикуму

## Тема

Моделирование колец Ньютона для линзы заданного радиуса. Рассматриваются монохроматический и квазимонохроматический свет. Результат моделирования: цветное распределение интенсивности интерференционной картины и график зависимости интенсивности от радиальной координаты.

## Цель работы

Построить интерактивную численную модель интерференционной картины в тонкой пленке между сферической линзой и плоской пластиной, проверить модель по аналитическим асимптотическим формулам и сопоставить расчет со стандартной экспериментальной методикой измерения колец Ньютона.

## Обоснование выбора модели

Кольца Ньютона возникают из-за интерференции лучей, отраженных от верхней и нижней границ тонкой пленки. Для учебной модели достаточно скалярного двухлучевого приближения, потому что оно воспроизводит основные наблюдаемые эффекты:

- темный центр в отраженном свете при нулевом зазоре;
- чередование темных и светлых концентрических колец;
- зависимость радиусов колец от длины волны и радиуса кривизны линзы;
- падение контраста при конечной ширине спектра.

Модель предполагает почти нормальное падение, гладкую сферическую поверхность линзы и однородную пленку с показателем преломления `n`.

## Теоретическая часть

Пусть `R` - радиус кривизны линзы, `r` - радиальная координата, `t0` - начальный зазор. Точная толщина пленки:

```text
t(r) = t0 + R - sqrt(R^2 - r^2)
```

При `r << R`:

```text
t(r) ~= t0 + r^2 / (2R)
```

Фаза интерференции для длины волны `lambda`:

```text
phi(lambda, r) = 4*pi*n*t(r) / lambda
```

Для отраженного света:

```text
I_ref(lambda, r) = I0 * (1 - V*cos(phi(lambda, r))) / 2
```

Для проходящего света:

```text
I_tr(lambda, r) = I0 * (1 + V*cos(phi(lambda, r))) / 2
```

Здесь `V` - видность интерференции. Для идеальной картины `V = 1`.

Темные кольца в отраженном свете удовлетворяют условию:

```text
2*n*t(r_m) = m*lambda
```

В параксиальном приближении при `t0 = 0`:

```text
r_m^2 ~= m*lambda*R / n
```

Для диаметра `D_m = 2*r_m`:

```text
D_m^2 ~= 4*m*lambda*R / n
```

Эта формула используется в лабораторной обработке данных: по наклону графика `D_m^2(m)` можно восстановить `lambda` или `R`.

## Квазимонохроматический источник

Источник с конечной шириной спектра описывается гауссовым распределением:

```text
S(lambda) = exp(-(lambda - lambda0)^2 / (2*sigma^2))
sigma = Delta lambda / (2*sqrt(2*ln(2)))
```

Итоговая интенсивность получается спектральным усреднением:

```text
I(r) = integral S(lambda)*I(lambda, r) dlambda / integral S(lambda) dlambda
```

Для цветного изображения дополнительно считается спектральная сумма в пространстве `XYZ`, затем выполняется перевод в `sRGB`.

## Численный алгоритм

1. Считать параметры из интерфейса: `R`, `lambda0`, `Delta lambda`, `t0`, `n`, `V`, радиус области наблюдения.
2. Построить спектральную сетку:
   - один отсчет для монохроматического света;
   - 81 отсчет с гауссовыми весами для квазимонохроматического света.
3. Для каждого радиального отсчета вычислить толщину пленки `t(r)`.
4. Для каждой длины волны вычислить фазу `phi(lambda, r)` и интенсивность.
5. Усреднить интенсивность по спектру.
6. Для цветного изображения вычислить `XYZ(r)` и перевести его в `sRGB`.
7. С учетом осевой симметрии заполнить Canvas через таблицу радиальных значений.
8. Построить график `I(r)`.

Оптимизация не меняет физику: вместо повторного вычисления спектрального интеграла в каждом пикселе он считается по радиальной сетке, так как картина зависит только от `r`.

## Листинг программного кода

Полный код находится в файлах проекта:

```text
src/physics.js      физическая модель, спектр, интенсивности, радиусы колец, цвет
src/app.js          интерфейс, чтение параметров, Canvas-рендер, график I(r)
src/styles.css      оформление
tests/physics.test.js автоматические тесты физических соотношений
scripts/report-checks.js численные проверки для отчета
```

Ключевые функции:

- `filmThicknessM(r, R, t0)` - точная толщина пленки;
- `interferenceIntensity(r, params)` - интенсивность для монохроматического света;
- `spectrumSamples(lambda0, Delta lambda, count)` - спектральная сетка;
- `spectralColorAtRadius(r, spectrum, params)` - спектральное усреднение интенсивности и цвета;
- `ringRadiusM(m, params)` - радиус темного или светлого кольца.

Фрагмент ключевого листинга из `src/physics.js`:

```js
function filmThicknessM(radialCoordinateM, curvatureRadiusM, gapNm) {
  var r = finiteNumber(radialCoordinateM, "radialCoordinateM");
  var radius = finiteNumber(curvatureRadiusM, "curvatureRadiusM");
  var gapM = finiteNumber(gapNm || 0, "gapNm") * 1e-9;
  var root = Math.sqrt(Math.max(0, radius * radius - r * r));
  var sagittaM = r === 0 ? 0 : (r * r) / (radius + root);
  return gapM + sagittaM;
}

function interferenceAtThickness(thicknessM, wavelengthNm, options) {
  var settings = options || {};
  var visibility = clamp(settings.visibility === undefined ? 1 : settings.visibility, 0, 1);
  var phase = phaseRadians(thicknessM, wavelengthNm, settings.refractiveIndex || 1);
  var cosine = Math.cos(phase);

  if (settings.mode === "transmitted") {
    return 0.5 * (1 + visibility * cosine);
  }
  return 0.5 * (1 - visibility * cosine);
}
```

Полный листинг находится непосредственно в исходных файлах проекта, перечисленных выше.

## Результаты численного решения

Типичные наблюдения при изменении параметров:

- при увеличении `R` кольца становятся шире, так как `r_m^2` пропорционально `R`;
- при увеличении `lambda` радиусы колец растут;
- при увеличении `Delta lambda` дальние кольца теряют контраст из-за уменьшения длины когерентности;
- в отраженном свете центр темный при `t0 = 0`;
- в проходящем свете картина комплементарна отраженной;
- при ненулевом `t0` центр может стать светлым или промежуточным в зависимости от фазы.

```text
http://localhost:8000
```

## Проверка по асимптотике

Проверка выполняется командой:

```bash
npm run check:report
```

В первой таблице сравниваются:

```text
r_exact = sqrt(2*R*s - s^2), где s = m*lambda/(2n)
r_asymptotic = sqrt(m*lambda*R/n)
```

Для малых `r/R` относительная ошибка мала, что подтверждает переход точной геометрической модели к аналитической формуле колец Ньютона.

Дополнительно автоматические тесты проверяют:

- темный центр в отраженном свете;
- комплементарность отраженной и проходящей картин;
- максимум первого светлого кольца;
- формулу первого ненулевого темного кольца;
- нормировку спектральных весов;
- предел `Delta lambda = 0`.

## Сравнение с экспериментальной методикой

В стандартной лабораторной работе измеряют диаметры темных колец и используют формулу:

```text
lambda = (D_(n+m)^2 - D_n^2) / (4*m*R)
```

Именно эта методика описана в лабораторных руководствах по кольцам Ньютона. В Манчестерском руководстве также указано сравнение результата с принятым значением длины волны натриевого света `589 нм`.

В проекте команда:

```bash
npm run check:report
```

строит контрольную таблицу: диаметры темных колец берутся из точной модели, затем длина волны восстанавливается по лабораторной формуле. Полученное значение сравнивается с `589 нм`. Это проверяет, что численная модель согласована с экспериментальной обработкой данных.

Если есть реальные измерения из лабораторной работы, их можно сравнить с моделью тем же способом: построить график `D_m^2` от `m`, найти наклон и вычислить `lambda` или `R`.

## Выводы

1. Построена интерактивная модель колец Ньютона для отраженного и проходящего света.
2. Модель воспроизводит стандартную физику тонкой пленки: темный центр в отраженном свете, концентрические кольца и зависимость `r_m^2 ~= m*lambda*R/n`.
3. Для квазимонохроматического света реализовано спектральное усреднение, показывающее уменьшение контраста дальних колец.
4. Численная модель проверена по аналитическим асимптотическим формулам.
5. Расчет согласован со стандартной экспериментальной методикой обработки диаметров колец Ньютона.
6. Реализована оптимизация рендера через радиальную симметрию, поэтому интерактивное демо остается быстрым без изменения физической логики.
