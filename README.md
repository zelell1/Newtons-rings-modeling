# Моделирование колец Ньютона

Интерактивное учебное демо для моделирования колец Ньютона у линзы заданного радиуса кривизны. Программа строит:

- цветное распределение интенсивности интерференционной картины;
- график зависимости нормированной интенсивности `I(r)` от радиальной координаты;
- монохроматический и квазимонохроматический режимы света;
- отраженную и проходящую интерференционные картины.

Проект написан без внешних фронтенд-зависимостей: `HTML + CSS + Canvas + JavaScript`.

## Быстрый запуск

Можно открыть `index.html` напрямую в браузере.

Для запуска через локальный сервер:

```bash
npm run serve
```

После запуска страница доступна по адресу:

```text
http://localhost:8000
```

Запуск тестов:

```bash
npm test
```

Проверки для отчета: асимптотика и восстановление длины волны по стандартной лабораторной формуле:

```bash
npm run check:report
```

Полный отчет по требованиям вычислительного практикума находится в `docs/report.md`.

## Возможности демо

В интерфейсе можно менять:

- режим наблюдения: отраженный или проходящий свет;
- радиус кривизны линзы `R`;
- радиус области наблюдения;
- центр спектра `lambda0`;
- ширину спектра `Delta lambda` в нанометрах;
- начальный зазор `t0`;
- показатель преломления пленки `n`;
- видность интерференции `V`.

Если ширина спектра равна `0 нм`, источник считается монохроматическим. При ненулевой ширине используется квазимонохроматический гауссов спектр, из-за чего дальние кольца постепенно теряют контраст.

## Физическая модель

Рассматривается сферическая линза на плоской пластине. Между линзой и пластиной находится тонкая пленка с показателем преломления `n`. Для радиальной координаты `r` толщина пленки:

```text
t(r) = t0 + R - sqrt(R^2 - r^2)
```

Для области `r << R` используется стандартное параксиальное приближение:

```text
t(r) ~= t0 + r^2 / (2R)
```

Оптическая разность хода для почти нормального падения:

```text
delta = 2*n*t(r)
```

Фаза:

```text
phi(lambda, r) = 4*pi*n*t(r) / lambda
```

### Отраженный свет

В отраженном свете один из лучей получает дополнительный фазовый скачок `pi`. Поэтому при `t0 = 0` центр картины темный:

```text
I_ref(lambda, r) = I0 * (1 - V*cos(phi(lambda, r))) / 2
```

Условия минимумов:

```text
2*n*t(r_m) = m*lambda,  m = 0, 1, 2, ...
```

При `t0 = 0` и `r << R`:

```text
r_m^2 ~= m*lambda*R / n
```

Условия максимумов:

```text
2*n*t(r_m) = (m + 1/2)*lambda
```

### Проходящий свет

Проходящая картина комплементарна отраженной:

```text
I_tr(lambda, r) = I0 * (1 + V*cos(phi(lambda, r))) / 2
```

Здесь `V` - видность интерференции. При `V = 1` получается идеальная двухлучевая интерференция, при `V = 0` кольца исчезают.

## Квазимонохроматический свет

Для источника с конечной спектральной шириной используется гауссов спектр. Пользователь задает центр спектра `lambda0` и ширину `Delta lambda` как FWHM:

```text
S(lambda) = exp(-(lambda - lambda0)^2 / (2*sigma^2))
sigma = Delta lambda / (2*sqrt(2*ln(2)))
```

Итоговая интенсивность получается спектральным усреднением:

```text
I(r) = integral S(lambda)*I(lambda, r) dlambda / integral S(lambda) dlambda
```

Длина когерентности оценивается как:

```text
L_c ~= lambda0^2 / Delta lambda
```

При росте `Delta lambda` длина когерентности уменьшается, и видимость дальних колец падает.

## Цветовая модель

Для цветной визуализации спектральный вклад переводится в `XYZ` через приближенные функции цветового соответствия CIE 1931:

```text
XYZ(r) = integral S(lambda)*I(lambda, r)*[xbar(lambda), ybar(lambda), zbar(lambda)] dlambda
```

Затем `XYZ` переводится в линейный `sRGB`, после чего применяется гамма-коррекция для отображения на Canvas.

## Оптимизация

Физическая логика считается по тем же формулам, но рендер использует осевую симметрию колец:

- цвет и интенсивность считаются по радиальной сетке;
- пиксели Canvas берут готовое значение из таблицы радиусов;
- для графика цвет и интенсивность берутся из одного спектрального интеграла.

Это сохраняет физическую модель, но убирает тяжелый попиксельный пересчет спектра.

## Проверки для отчета

Скрипт `scripts/report-checks.js` печатает две таблицы:

- сравнение точного радиуса темного кольца с асимптотической формулой `r_m^2 ~= m*lambda*R/n`;
- восстановление длины волны натриевого света по лабораторной формуле `lambda = (D_(n+m)^2 - D_n^2)/(4mR)`.

Команда:

```bash
npm run check:report
```

## Тест-кейсы

В тестах проверяется:

- темный центр в отраженном свете при `t0 = 0`;
- комплементарность отраженной и проходящей картин;
- максимум первого светлого кольца;
- формула первого ненулевого темного кольца `r^2 ~= lambda*R`;
- совпадение нулевой спектральной ширины с монохроматическим расчетом;
- нормировка гауссовых спектральных весов;
- совпадение точной сагитты линзы с приближением `r^2/(2R)` в параксиальной области.
