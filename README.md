# Моделирование колец Ньютона

Интерактивное учебное демо для моделирования колец Ньютона у линзы заданного радиуса кривизны.

Программа строит:

- цветное распределение интенсивности интерференционной картины;
- график нормированной интенсивности `I(r)` по радиальной координате;
- монохроматический и квазимонохроматический режимы света;
- отраженную и проходящую интерференционные картины.

Проект написан без внешних фронтенд-зависимостей: `HTML + CSS + Canvas + JavaScript`.

## Параметры демо

В интерфейсе можно менять:

- режим наблюдения: отраженный или проходящий свет;
- радиус кривизны линзы `R`;
- радиус области наблюдения;
- центр спектра `lambda0`;
- ширину спектра `Delta lambda` в нанометрах;
- начальный зазор `t0`;
- показатель преломления пленки `n`;
- видность интерференции `V`.

Ширина спектра `0 нм` означает монохроматический источник. При ненулевой ширине используется
квазимонохроматический гауссов спектр, поэтому дальние кольца постепенно теряют контраст.

## Физическая модель

Толщина пленки между линзой и пластиной:

```text
t(r) = t0 + R - sqrt(R^2 - r^2)
```

В параксиальном приближении:

```text
t(r) ~= t0 + r^2 / (2R)
```

Фаза:

```text
phi(lambda, r) = 4*pi*n*t(r) / lambda
```

Отраженный свет:

```text
I_ref(lambda, r) = I0 * (1 - V*cos(phi(lambda, r))) / 2
```

Проходящий свет:

```text
I_tr(lambda, r) = I0 * (1 + V*cos(phi(lambda, r))) / 2
```

Для темных колец в отраженном свете:

```text
2*n*t(r_m) = m*lambda
r_m^2 ~= m*lambda*R / n
```

Для квазимонохроматического света:

```text
S(lambda) = exp(-(lambda - lambda0)^2 / (2*sigma^2))
sigma = Delta lambda / (2*sqrt(2*ln(2)))
I(r) = integral S(lambda)*I(lambda, r) dlambda / integral S(lambda) dlambda
```

## Тест-кейсы

В тестах проверяется:

- темный центр в отраженном свете при `t0 = 0`;
- комплементарность отраженной и проходящей картин;
- максимум первого светлого кольца;
- формула первого ненулевого темного кольца `r^2 ~= lambda*R`;
- совпадение нулевой спектральной ширины с монохроматическим расчетом;
- нормировка гауссовых спектральных весов;
- совпадение точной сагитты линзы с приближением `r^2/(2R)`;
- восстановление длины волны по лабораторной формуле через диаметры колец.
